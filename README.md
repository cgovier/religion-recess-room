# religion-recess-room.github.io
Welcome to Religion Recess Room! A fun and interactive website where students can learn about religion while playing educational games. Explore quizzes, puzzles, and activities designed to teach important concepts in a playful way. Discover, learn, and have fun all in one place!
## 🚀 Features
- **Meme Gallery:** 40+ curated educational memes.
- **Interactive Quizzes:** Challenge your knowledge (In Progress).
- **Clicker Challenge:** A fast-paced mini-game for students.

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS (via CDN), Vanilla JavaScript.
- **Hosting:** GitHub Pages.

## 📂 Project Structure
- `index.html`: Main hub and landing page.
- `clicker-challenge.html`: Mini-game page.
- `/assets`: Contains all visual media and artifacts.
